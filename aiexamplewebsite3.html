🐍 สรุปคำสั่งพื้นฐาน Python

รวมตัวอย่างโค้ดสั้นๆ เข้าใจง่าย พร้อมปุ่มคัดลอกเพื่อนำไปใช้งาน

1. Output & Input (การแสดงผลและรับค่า)

ใช้คำสั่ง print() สำหรับแสดงข้อความออกทางหน้าจอ และ input() สำหรับรับค่าที่ผู้ใช้พิมพ์เข้ามา

# การแสดงผล (Output) print("สวัสดี, ชาวโลก!") # การรับค่า (Input) name = input("คุณชื่ออะไร: ") print("ยินดีที่ได้รู้จัก, " + name)
ผลลัพธ์ตัวอย่าง: สวัสดี, ชาวโลก! / (โปรแกรมรอรับค่าพิมพ์ชื่อ)

2. Function (ฟังก์ชันและการสร้างคำสั่งย่อย)

ใช้คำสั่ง def เพื่อสร้างฟังก์ชันสำหรับเก็บชุดคำสั่งไว้เรียกใช้งานซ้ำๆ ได้ และสามารถส่งค่า (Arguments) เข้าไปคำนวณได้

# ประกาศฟังก์ชันสำหรับทักทาย def say_hello(name): return f"สวัสดีคุณ {name}!" # เรียกใช้งานฟังก์ชัน message = say_hello("สมชาย") print(message)
ผลลัพธ์ตัวอย่าง: สวัสดีคุณ สมชาย!

3. Condition (เงื่อนไข if-elif-else)

ใช้ตรวจสอบเงื่อนไขทางเลือก ว่าถ้าเป็นจริงให้ทำชุดคำสั่งนี้ ถ้าไม่ใช่ให้ไปเช็คเงื่อนไขอื่นหรือทำคำสั่งสำรอง

score = 75 if score >= 80: print("ได้เกรด A") elif score >= 50: print("ผ่าน (Pass)") else: print("ไม่ผ่าน (Fail)")
ผลลัพธ์ตัวอย่าง: ผ่าน (Pass)

4. Loop (การวนซ้ำ for และ while)

ใช้สำหรับสั่งให้โปรแกรมทำงานซ้ำๆ หลายรอบโดยไม่ต้องเขียนโค้ดเดิมซ้ำๆ เช่น การใช้ for วนลูปตามจำนวนครั้งที่กำหนด

# วนลูปนับเลข 1 ถึง 3 ด้วย for loop for i in range(1, 4): print(f"รอบที่: {i}")
ผลลัพธ์ตัวอย่าง:
รอบที่: 1
รอบที่: 2
รอบที่: 3
